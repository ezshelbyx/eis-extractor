# Changelog

## [0.1.0] - 2026-11-18
### Added
- Initial release of E.I.S EXTRACTOR.
- Native Linux archive manager (C++20 + Qt 6 Widgets).
- Support for ZIP, TAR, 7Z, RAR, ISO and more.
- Six-section UI, job queue, integrity lab, activity log.
- Dolphin service-menu integration.
- Fedora RPM packaging.
